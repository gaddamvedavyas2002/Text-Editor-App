# Text Editor

A beautiful and responsive text editor built with **React** and **Styled Components**. Supports real-time text formatting with Bold, Italic, and Underline options.

![Text Editor Preview](https://assets.ccbp.in/frontend/react-js/text-editor-img.png)

## ✨ Features

- **Bold** formatting
- **Italic** formatting  
- **Underline** formatting
- Fully responsive design (Mobile + Desktop)
- Clean dark UI with smooth hover effects
- Real-time style preview in textarea

## 🛠️ Technologies Used

- **React** (Class Component)
- **Styled Components**
- **React Icons** (VscBold, GoItalic, AiOutlineUnderline)
- Responsive Design with Media Queries

## 📱 Responsive Behavior

- On desktop: Side-by-side layout (Left panel + Editor)
- On mobile: Stacked layout with centered controls
